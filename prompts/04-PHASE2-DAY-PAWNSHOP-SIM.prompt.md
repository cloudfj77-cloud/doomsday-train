## 目标
实现黑店白昼与打烊工作台（`pawnshop` 模块），通过天工引擎 `frontend` 层的响应式 UI 与 3D 后屋背景联动，完整落地《可能是偷的》全部核心博弈乐趣，并与夜间 3D 搜打撤无缝咬合。

## 必做系统与交互清单

1. **日程三态与「队列即时钟」**：
   - **清晨晨报 (`MORNING`)**：展示昨夜机器产出、赃物降温日志、今日市场新闻头条（15 种动态市场事件，如「净水管爆裂：饮用水 +55%」「海关严打：军火溢价 +40% 且盘查加密」「流感蔓延：医疗品 +65%」）、距离周日交租剩余天数与金额。
   - **拉起卷帘门营业 (`SHOP_OPEN`)**：一次性按优先级栈生成今日顾客队列（展示柜吸客 + 剧情熟客 + 例行/突击治安盘查员 + 通缉犯 + 周日流动性收购商 + 按声望分布抽样的随机派系客）。
   - **逐客博弈主柜台**：
     - 左侧：库存区、**展示柜**（摆上特定品类吸引高预算对口买家，但摆违禁品会招来突击盘查！）、**海报后 2×2 走私暗格**（一键拖入/移出，盘查员瞎眼看不见！）。
     - 中央：当前顾客生动鸭系半身像素矢量立绘、派系徽章、隐藏破绽特征（通缉令比对特征：刀疤/金牙/义眼/红围巾；罪犯黑话破绽）、对话气泡与报价单。
     - 右侧：**三合一验货与造假工作台** + **公开概率议价面板**。

2. **三仪器验货 + 贴假标造假（双值结构核心玩法）**：
   - **收购验货**：顾客拿来卖的货往往虚标高档位（如把劣质组装枪标成军规精品）。玩家点击【紫外放大镜】（查外观/封条/序列号）、【化学试纸】（查水纯度/药剂真伪）、【频谱扫描仪】（查芯片/金属内伤/赃物暗码）即可揭穿 `actualGrade`，收货价立刻暴跌并解锁「指出瑕疵再压价 15%」！
   - **出货贴假标**：玩家花少量耗材费在【贴标机】上把低档货（或夜袭捡来的残次战利品）改写 `claimedGrade` 为「军规/特级」，高价卖给不识货的观光鸭团（`0%` 识破）或金羽上层区（`15%` 识破），体验刀尖舔血的暴利！

3. **公开概率议价与特殊交互**：
   - 实时计算并透明显示每档报价（`原价` / `±10%` / `±25%` / `±50%`）的 **接受率 %**、**拒绝留店率 %**、**愤而离店率 %** 以及预估 **声望变动**。
   - 特殊按钮：
     - **【敲诈 ±20%】**：识破顾客是隐藏罪犯时拍桌敲诈，双向压榨利润；
     - **【按下柜台下报警器】**：比对每日通缉单特征，抓获真通缉犯当场领 `350~800 cr` 赏金 + 治安声望 `+8`（误报罚 `80 cr`、声望 `-8`；放走无任何惩罚，保留道德留白）。

4. **治安盘查危机时刻**：
   - 盘查员进店亮证时，根据是否购买「治安线人」提前预警；面对 `严格 / 可贿赂 / 懒惰` 三种人格，玩家可选择：**坦然受检**、**塞黑钱行贿**（计入贿赂暗账），或在盘查员登门前提前把 C2~C4 违禁品锁进 **海报暗格**！

5. **打烊后屋：4 条夜间机器生产链 + 王尔德人脉升级网 + 夜袭整备**：
   - **后屋生产机器**（每夜结算一次产出，与夜袭搜刮原料直接挂钩）：
     1. `净水蒸馏塔`：夜袭滤芯/脏水 → 特级纯净饮用水；
     2. `地下化学合成台`：化学前体 + 止痛药 → 高纯度药用合剂（高杠杆违禁品 C3）；
     3. `3D 军工打印与翻新台`：废金属锭 + 战损枪械 → 满耐久精工武器或战术配件；
     4. `J-Lab 磁芯解序仪`：加密软盘/门禁卡 → 高价值情报芯片或 J-Lab 37号实验区通行证！
   - **王尔德人脉网**：使用「王尔德恩惠」（优先抵扣）+ 现金解锁：治安线人、善后人消证、暗格扩容、柜台交易终端、夜袭安全箱扩容、黑市高价渠道、租金宽限与豁免权。
   - **夜袭整备与休息二选一**：既可一键「锁门安睡（稳健流）」，也可换装武器护甲点击「潜入封锁区夜袭（硬核暴利流）」切入 3D 战场！
</task_prompt>
