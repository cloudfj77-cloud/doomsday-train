## 目标
基于 `@forgeax/engine@0.4.19` 与 `Prompt 02` 的统一状态层，构建《鸭科夫黑店》的夜间 3D 俯视搜打撤战场插件（`raid` 模块）。当玩家在黑店打烊后点击「潜入封锁区夜袭」时，激活 3D 战区渲染与物理模拟；白天在店内经营时，3D 镜头自动切换为地堡后屋微缩立体背景展示。

## 必做视觉与体验清单

1. **标志性鸭科夫微缩镜头 (`CameraArmControl` 还原)**：
   - 俯仰角 `Pitch = 55°`、偏航角 `Yaw = -30°`、窄视场角 `FOV = 22°`（弧度）、相机距离 `24~28m`，配 `TONEMAP_ACES_FILMIC` 与 `ANTIALIAS_FXAA`。
   - 瞄准前探偏移（Aim Offset）：用 `viewportToWorld` 将鼠标屏幕坐标投射到 `y = 0` 地面得到瞄准点，相机焦点向鼠标瞄准方向平滑前探 `1.8m`，视野先人一步。

2. **模块化可爱战术鸭 vs 写实枪械反差建模（程序化 Mesh 组装）**：
   - **主角与敌人鸭**：圆润土豆形鹅黄/灰羽鸭身 + 扁宽橘色鸭嘴 + 双蹼小短腿（移动时交替摆动）+ 按当前穿戴 `helmet` / `bodyArmor` 等级动态切换外观的战术头盔（LV1 破安全帽 → LV3 钢盔 → LV6 重装夜视特种头盔）与防弹背心 + 手持写实比例枪械模型 + 背负战利品背包。
   - **敌人类型**：
     - `暴走拾荒鸭 (Scav)`：提切肉刀或土制猎枪，移速快、近身莽撞；
     - `乌鸦巡逻兵 (Crow Merc)`：配冲锋枪/AK，中等护甲，会依托掩体射击；
     - `铁喙重装卫队 / 机械蜘蛛 (J-Lab Guard)`：高护甲（需穿甲弹或电/火元素克制），守护高价值保险箱；
     - `战区首领 · 狙击手劳登 / 急速团长`：高血量高爆伤，必掉紫/金级违禁品或剧情软盘。

3. **4 大可选封锁战区（随天数/钥匙卡/情报解锁）**：
   - `零号街区 (Ground Zero)`：废弃加油站与路障街道，低风险，产纯净水芯、初级医疗包、基础枪械；
   - `码头暗仓 (Hidden Warehouse)`：集装箱迷宫与海关办公室，中风险，产赃物名表、香烟、枪械配件、监控硬盘；
   - `迷雾农场镇 (Farm Town)`：谷仓、水培温室与宿舍楼，中高风险，产变异种子、化学前体、三级甲；
   - `J-Lab 37号实验区 (Storm / J-Lab)`：高危实验舱与暴雨雷电区，需实验区通行卡，遍布重装守卫，盛产 C3/C4 超科技违禁品、加密软盘与金色五角星！

4. **AI 视锥 + 声波听觉 + 昼夜天气联动**：
   - 每名敌人拥有扇形视锥与近身直觉圈；雨夜天气下视距衰减 `25%`，但玩家的枪声（无消音器 `16m` / 装消音器 `6.5m`）与冲刺脚步声会向周围广播唤醒敌人。
   - 命中反馈：被击中瞬间材质受击闪白 `0.09s`（致敬 `SodaCharacter _HurtValue`），地面弹出伤害数字（爆头金色暴击标记、护甲抵消银色标记），枪口火光点光源闪烁 + 弹道曳光束。

5. **品质读条搜刮 & 绿色烟雾倒计时撤离**：
   - 靠近物资箱按 `E`（或点击）打开战地搜刮浮层：未鉴定格子按稀有度读条 `0.45s ~ 2.8s`，玩家可一键收入战利品背包（容量受背包等级限制，另有 2 格死亡不掉的「地堡安全箱」）。
   - 地图边缘生成 2 个绿色信号烟柱撤离点 (`CountDownArea`)：踏入圈内倒计时 `4.0s` 即可安全撤离回店；若生命归零或战区氧气/宵禁倒计时耗尽，损失背包与身上装备（安全箱物品保留），带伤狼狈逃回地堡进入次日清晨。
</task_prompt>
