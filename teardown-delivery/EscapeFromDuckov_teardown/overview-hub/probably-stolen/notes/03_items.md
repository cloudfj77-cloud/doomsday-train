# 03 · 物品体系、鉴定检验、生产链与机器 —《Probably Stolen》逆向拆解

> 来源：`~/ps_work/src/*.cs`（反编译 C#，Unity 2021.3 Mono），本地化 `~/ps_work/loc/chinese.json`。
> 每条结论后标注 `文件:行号` 或 `文件` 级来源。数值单位：信用点(cr)；液体内部单位 1 mL = 1000 parts（µL）。
> 时间单位：店内所有生产机器以 **“夜”** 为一个周期结算（`PlayerStore.cs:1755-1766` 夜间对所有物品调用 `onCycleEndSlotItemFunc`），回合制 `onTurnEnd` 只用于旧版 Raid/飞船玩法（`TurnManager.cs:98-150`）。

## 0. 速读结论

| 维度 | 一句话 |
|---|---|
| 数据模型 | `GameItem` 本体很“薄”：只有 `unitValue`、`unitCount`、`shape` 等少数字段，**真伪/纯度/耐久/赃物/违禁全部挂在 Tag（TagSystem）+ ItemFeature（标签条）上**，价格由三段式公式合成。 |
| 核心骗局结构 | 每个 `ItemFeature` 有 **fakeCondition（标签上写的）与 realCondition（实际）**；未揭穿时按假标签计价，揭穿（Expose）后按真实值计价——整套“鉴定 / 贴假标 / 被识破”玩法都是这一个双值结构的不同 UI。 |
| 检验小游戏 | 目检找茬（香烟/食品券/注射器）、仪器测量（水：手电/试纸/扫描仪；化学：光谱仪；金属锭：手电/检测器；植物：分析仪/基因扫描仪）、估价（鉴定公会：义手/肋明治/等离子燃料匣）、弹药箱核对。 |
| 产业线 | 水、化学（毒品/药片）、枪械（打印+改装+订单）、水培（含基因编辑）、水产、畜牧（鼠）、酿酒、冶炼/回收、钥匙卡解序；器官/采矿/肉类培养为未完成或旧版残留。 |
| 毁灭方式 | 不是“一次性被抓”，而是**延迟累积的犯罪账本**（脏水/错标水/劣质化学/危险品 tracker，每夜衰减很慢）+ 随机安检（赃物热度=被查出概率）+ 客户识破扣阵营声望 + 生物系统自身崩溃（污染、朊病毒、废水）。 |

## 1. 物品数据模型

### 1.1 GameItem 核心字段（`GameItem.cs:48-154`）

| 字段 | 含义 | 备注 |
|---|---|---|
| `identifier` / `uniqueId` | 物品类型 ID / 实例唯一 ID | 类型 ID 由各 `*Directory.Add("id", factory)` 注册 |
| `name/shortDescription/longDescription/flavorText` | 文本 | 多用 `LocHelper.GetLocalizedItem` |
| `unitValue` | **单件基础价值** | 唯一的“价格”主字段；揭穿香烟/注射器时直接被改写（`ItemConditionActionList.cs`） |
| `lateUnitValue` | 杂项附加值（不吃百分比的 innate 乘区） | `GetItemMiscValue` |
| `unitBaseValue` / `backupUnitValue` | 电池等复合件的底价 / 备份 | `PowerHelper.GetPowerSourceItemValue` = 电量 + unitBaseValue（1 电 = 1 cr） |
| `unitCount` | 堆叠数量 | `GetValue()` = 单价 × 数量 |
| `shape` / `modifiedShape` | 网格形状（多格骨牌） | **由精灵图 alpha 自动生成**（`BuildShapeFromSprite`，`GameItem.cs:348-372`） |
| `state` / `modifiedState`（TagSystem） | 万能状态袋：int/string/bool/float/double 标签 | 真伪、纯度、耐久、赃物热度、违禁等级、枪械属性、植物基因等全部是 Tag |
| `itemFeatures: List<ItemFeature>` | “标签条”（价格修正 + 可揭穿信息） | 见 1.3 |
| `itemTypes: List<string>` | 商品类型（WATER/FIREARM/LUXURY_ITEM…） | 影响市场事件、客户偏好、许可证覆盖 |
| `contentWindow` | 容器内部窗口 | 背包、机器、仓储舱都是“带窗口的物品” |
| `effects/bonusAccuracy/...` | 旧版战斗字段 | Raid 残留 |

### 1.2 价值公式（三段乘区）——`GameItem.cs:1711-1814`

```
base   = unitValue + 复合件值(电池电量)
innate = Σ 特性.mod (ValueStage.Innate：纯度/成色/耐久/真伪…)
market = Σ 特性.mod (ValueStage.Market：市场事件、零售加价15%、违禁加价、客户折扣、香水…)
final  = Π (1 + 特性.mod/100) (ValueStage.Final：讨价还价/勒索/威胁)
价格 = round( ( max(0, base×(1+innate%)) + 容器底价 ) × (1+market%) + misc(子物品值+lateUnitValue) ) × final
```

- 容器底价（瓶子本身）在 innate 之后加入，所以水纯度不放大瓶子价（`WaterHelper.GetContainerPrice`）。
- 子物品（背包里的东西、枪上的配件）以 `GetCurrentChildValue` 计入，并继承父物品的临时客户市场修正（`GetInheritableClientMarketMod`）。
- 下限 0（`CheckValueSafe`）。

**常驻市场修正数值**（`PlayerStore.cs:97-109`, `ItemFeatureList.cs`）

|---|---|

### 1.3 ItemFeature / ItemCondition：真伪双值结构（`ItemFeature.cs`, `ItemCondition.cs`, `ItemConditionList.cs`）

- `ItemFeature`：`featureType`(Normale/Event/Special/Temporary/TemporaryBuying/TemporarySelling/ClientTemporary)、`valueStage`、`publicDisplay/actualDisplay`、`valueModifier/preExposeValueModifier`、`fakeCondition/realCondition`、`isFeatureExposed`、`isFeatureDiscovered`、`removedByTool`。
- 计价：`GetCurrentValueMod()` → 未揭穿用 **fake**，揭穿后用 **real**（`ItemFeature.cs:380-400`）。
- `IsFeatureMatch()`：fake.id == real.id 时视为“标签属实”，客户/安检不会追究。
- `isFeatureDiscovered`：玩家用工具测过（tooltip 显示绿=属实/红=不符，`LabelerHelper.HandleLine`）。
- 揭穿可触发 `onActivateActionId`，直接改写物品名称与 `unitValue`（例：香烟真品 100 / 假货 50；注射器真 160 / 过期 80 / 假 40 / 失效 8；食品券假货 8 且不可使用，`ItemConditionActionList.cs`）。

## 2. 鉴定 / 检验小游戏

### 2.1 总体框架

```
物品带 ItemFeature(fake, real)
 ├─ 玩家收货（客户卖给你）：用工具 Discover → 发现不符 → “对质 Confront”
 │     成功：Expose（价格按真值）+ 额外 −15% 折扣（ConfrontSucessDiscount）；
 │     失败（指错问题）：该客户阵营声望 −2（InspectionUIManager.cs:479-489）
 │     每件物品只能对质一次（ALREADY_CONFRONTED_TAG）
 └─ 玩家出货（你卖给客户）：客户按其阵营“识破能力”检查
       识破：Expose（降回真价）+ 阵营声望 −4（StoreClient.cs:794-807）
       NegociationHelper 路径的识破 −1（NegociationHelper.cs:OnFeatureExposed）
       未识破成交 → 计入安全部门“犯罪账本”（见第 4 章）
```

**客户识破能力矩阵**（`ClientCanExposeFunc.cs`，按阵营分配于 `StoreClient.cs:565-590`）

| 客户 | 水（手电：仅<96% 即铁锈/沟渠） | 水（试纸：任何错标） | 香烟 | 注射器 | 化学纯度 |
|---|---|---|---|---|---|
| 拾荒者 SCAV | ✔ | | ✔ | ✔ | 若 `CanExposeChem` |
| 下层区/黑市 LL/BM | | ✔ | ✔ | ✔ | 若 CanExposeChem |
| 治安部 SEC | | ✔ | ✔ | ✔ | 若 CanExposeChem |
| 游客 TOURIST | ✔ | | ✘ | 仅明显失效/过期 | ✘ |
| 上层区 UL | ✔ | | ✘ | 仅明显失效/过期 | 若 CanExposeChem |
| 其他 Basic | ✔ | | ✔ | | |
| 交易板/特殊 | 所有可贴标类别全识破 | | | | |

> 设计含义：**骗局的“目标客群”被硬编码**——假烟卖给游客/上层区不会被识破；幽灵水贴“基础水”卖给只会打手电的人也看不出来；而黑市和治安部带试纸。

### 2.2 各商品检验方式

#### ① 香烟目检（海明威，`InsCigaretteHelper.cs`, `PreBuiltItemHelper.cs:1194-1270`）
- 检查点：封条 SEAL（2 种）、Logo（5 种）、字体 LETTERING（8 种）、盒色 BOX/COLOR（4 种）。配合道具《海明威鉴定指南》《海明威色卡》+ 放大镜。
- 假货生成：循环掷骰直至至少 1 个瑕疵：封条 10%、Logo 20%、字体 30%、颜色 20%（可多个）。
- 随机香烟分布（视觉检验教学后）：20% 假货（如实标假）、40% **假货冒充真品**、30% 真品、10% **真品被说成假货**（卖家低估，玩家捡漏）。教学前：30% 真 / 70% 假。
- 价值：目录 80；揭穿为真 → 100 且加 LUXURY_ITEM；揭穿为假 → 50 并移除奢侈品类型。

#### ② 食品券（`InsStampHelper.cs`, `PreBuiltItemHelper.cs:1364-1510`）
- 面额 40/80/120/160/200（链式掷骰，最终约 34%/17%/17%/17%/15%），`unitValue = 0.75 × 面额`。
- 检查点：封条（**仅 ≥160 面额应有封条**）、Logo(6)、芯片 CHIP(4)、字体(9)、面额（假券可能多印 +10，如“90”）。
- 假券瑕疵概率：Logo 20、芯片 20、字体 20、面额 12、封条 10（%）。随机食品券 75% 真 / 25% 假。假券揭穿后 8 cr 且不可使用。

#### ③ 注射器“免疫宁”（`InsInjectorHelper.cs`）
- 正确厂商 `Carmicheal Pharmaceutical`、型号 `Immunivax`；序列号前缀黑名单（召回批次）{250,251,301,355,385,386,421}。
- 四态：真品 160 / 过期（指示窗变色）80 / 假货（序列号错 25%、颜色/机身错、型号或厂商拼错）40 / 失效（指示器损坏、机身破损、召回序列号）8。
- 随机分布（均自称真品）：过期 20%、失效 20%、假货 18%、真品 42%。

#### ④ 水质检测（`WaterHelper.cs`, `WaterFeatureHelper.cs`, `WaterScannerUIManager.cs`, `WaterStripUIManager.cs`）
- 纯度 = 水 part / 总 part（万分比）。六档：纯水 ≥99.9%、优质 99–99.9%、基础 98–99%、幽灵水 96–98%、铁锈水 90–96%、沟渠水 <90%。
- 三级工具：
  | 工具 | 价格 | 能力 |
  |---|---|---|
  | 手电筒 | 40 | 仅能确认 <96%（铁锈/沟渠）；否则只得“幽灵水或更好”（INCONCLUSIVE） |
  | 水质检测试纸 | 3/张（一次性） | 精确纯度 + 自有货可“Match”改标签为实测值 |
  | 水质扫描仪 Aquascan | 200 | 精确纯度 + 列出全部 36 种液体成分比例；可 Confront/Match |
- 对质：客户卖给你错标的水 → 揭穿压价；自己的水 → Match（把标签改成真值，合法化）。

#### ⑤ 化学纯度（`ChemicalProductHelper.cs`, `ChemScannerUIManager.cs`）
- 纯度 = 活性成分 / 总体积：≥99 实验室纯、≥90 药用、≥80 准药用、≥60 街头标准、≥45 掺假、≥30 垃圾、其余淀粉级。
- 成分光谱仪 400 cr：显示成分、欣快/毒性/避孕/Synaprest 效果条。
- 若真实纯度高于标签 → 主动告知客户，阵营 +3 声望（`ChemicalProductHelper.GetChemicalFeatureDialog`）。

#### ⑥ 金属锭纯度（`IngotPurityHelper.cs`）
- 手电：仅能看出“低/极低”；检测器/分析仪：全部。客户检查类型 `CHECK_INGOT_FLASHLIGHT/DETECTOR`。
- 纯度不可被贴标机改写（`LabelerHelper.CanEditLabel`）。

#### ⑦ 枪械：成色、许可与弹药箱（`GunHelper.cs`, `PermitHelper.cs`, `AmmoBoxHelper.cs`）
- 成色（全新…差）既改价格（±25%）又改六项属性（±30%）。
- 许可证 I/II/III 级：持证后对应等级枪械从“违禁”变“管制”（`SetRestrictedClass`），安检不再没收，售价加成减半；吊销则恢复违禁。
- 弹药箱：6 发一盒，客户核对数量/口径/类型，不符被揭穿（`AmmoBoxHelper.ClientCanExposeAmmoBox`）；卖劣质弹药累积 `badAmmoTracker`。

#### ⑧ 鉴定公会估价（`AppraisalRankHelper.cs`, `AppraisalServiceHelper.cs`, `AppraisalItemRegistry.cs`）
客户拿来东西请你**报价**（不是买卖），按精度收费。

| 鉴定物 | 解锁等级 | 真值公式 |
|---|---|---|

- **枪械订单**（`GunOrderData.cs`）：T1 基础报酬 63–110、T2 190–210、T3 350–370（+0–10 随机）；附加条件每条 +12～+46；报酬 × (100 + 武器市场事件% + 零售加价%)；“最佳枪”订单 = 市价 +50%。维修订单底费 30/60/100 + 每级属性步进奖励 15/25/40、12/20/32。

### 3.8 冶炼 / 回收 / 采矿

- 熔炉：每夜从左栏取 2 件（高炉 3 件）废金属(10)/矿石(15) → 1 锭(50)（高炉出 2）。纯度 = “低” + round(2×矿石占比) + 助熔剂等级（基础助熔剂 4cr 至少+1 并消耗；高级助熔剂 300 至少+1 不消耗）+ 质量加成/100（高炉 −1）。
  - 例：2 废金属 → 低纯(−15%)=42.5；2 矿石 → 高纯(+25%)=62.5；+完美纯度 = 150。
- 回收：损坏机器用螺丝刀/剪线钳/等离子切割机拆解得螺丝、线缆、废金属（`MachineBrokenHelper.cs`）；垃圾场拾荒（扫描仪/手电/工具各 +10% 对应材料）。
- `MiningHelper`（小行星采矿：8% 稀有矿、每多采 1 次事故率 +20%）与 `SalvageSystemHelper`（残骸打捞）只被飞船旧玩法引用，**当前店铺版本未接入**。

### 3.9 酿酒（`WineHelper.cs`, `MachineWineRack.cs`）

```
酒瓶(12) + ≥750mL 水 + 荧光莓×N(14，成色−2..+2) + 酵母
  → 发酵 4/酵母强度 夜（酵母2→2夜；超级酵母4→1夜；合成酵母 C1 2）
  → 成品酒基价 100 × 酒质修正 ；每夜陈化 +3 cr（催陈器加速）
酒质分 = Σ莓成色(负值+1) + (≥2莓 +1) + (有酵母 +1) + 水质(纯/优+1, 基础0, 幽灵−1, 铁锈−2, 沟渠−3)
  ≥6 大师年份 +75% | 5 珍藏 +50% | 3-4 量产 +25% | 2 家酿 0 | 1 桶酿 −15% | ≤0 不可饮 −100%
```
- 合成酵母 → “阴莓酒”：固定 44 cr，C2 违禁，带 `ENDANGERMENT_ITEM_TAG`（计入危险品账本）。

### 4.1 贴标机（`LabelerHelper.cs`, `LabelerUIManager.cs`）
- 50 cr 工具，对物品使用 → 修改 `fakeCondition`（并重置为未揭穿）；可“重复上次标签”批量操作。

- **不可篡改**：金属锭纯度、装备成色、酒质（`CanEditLabel`）。蓝色标签打印机只能改名。

### 4.2 风险层 1：当场识破

### 4.3 风险层 2：延迟犯罪账本（`SecData.cs`, `PlayerStore.CheckCrime`）

| 账本 | 累积方式 | 每夜衰减 | 触发阈值 | 后果 |
|---|---|---|---|---|
| 脏水 dirtyWater | 售出未揭穿的**幽灵水**：mL × 权重（标基础×1、优质×2、纯水×4） | −5 | 2500 | 每 500 记 ENDANGERMENT 20 + 匿名威胁信 |
| 错标水 mislabeledWater | 基础标优质×1、基础标纯×2、优质标纯×1.5、沟渠标铁锈×0.25 | −5 | 2500 | 每 500 记 FRAUD 20 |

- 游客购买不计入水账本（`SecData.cs:682`）——“坑游客”被设计为相对安全的灰色空间。

### 4.4 风险层 3：安检（`ContrabandHelper.StartInspection`）
- 搜查范围：仓库、前台、后台、展柜、垃圾桶（懒惰检查员跳过垃圾桶），海报后的暗格只有海报被掀开时才查；走私暗格（ITEM_HIDDEN）、上锁容器不查。
- 赃物：以“热度%”概率被发现；违禁品必被发现；运气属性可整体豁免一次。
- 处罚按最高等级：LOW 警告；STOLEN 没收赃物；MID 没收；HIGH 罚款 = 被查物品 unitValue 之和（付不起 → 逮捕）；CRITICAL 直接逮捕（“安全宽限”升级可改为扣声望）。
- 治安声望扣减 = Σ(1 + 违禁等级 + 赃物价值档 1–4)，上限 25；清白通过 +3。
- 走私贩运额检定（`CheckIfContrabandWasFound`）：≤100 → 10%、≤400 → 25%、≤750 → 35%、≤1000 → 50%、≤2000 → 90%、>2000 必中。

### 4.5 销赃（职业：销赃商 fence）
- 赃物热度初始化按基础价：≤17 不算赃物；<50 → 25；<85 → 50；<140 → 75；≥140 → 100（`StolenHelper.InitStolenItem`）。
- 每夜降温 18，违禁品降得更慢（L/M/H/C：16/14/12/10）。降到 0 即“洗白”。
- 收赃折扣 −10%～−25%（热度越高越便宜）；**卖给黑市时阵营声望 ×1.5/×2/×2.5/×3**（`StolenHelper.GetStolenItemTradingRepBonus`，`StoreReputation.cs:233`）；严重违禁品声望 ×(等级/2+1)。
- 销赃开局：破旧走私暗格、2 梦尘、一般成色铁铸10+弹药、医疗/工程/治安钥匙卡、2 暗灯；现金 −150、房租 +50、黑市声望 +30、治安 −30、解锁地下交易所（`NewGameData.cs:169-188`）。
- 持有赃物的经营曲线：**囤货等降温**（仓储成本 + 夜间安检风险） vs **立刻高价倒手给黑市刷声望**。

## 7. 设计点评：每条产品线的“利润曲线”与“毁灭方式”

> 共同骨架：**同一个 fake/real 双值** + **夜间结算** + **三段价格乘区** + **按阵营硬编码的识破能力** + **缓慢衰减的犯罪账本**。各产业线只是往这副骨架上挂不同的“原料-工艺-品质”变量，因此每条线的利润曲线与毁灭方式都能用统一的旋钮调节。

| 产业线 | 利润曲线（怎么赚、怎么增长） | 毁灭方式（怎么死） | 实现手段 |
|---|---|---|---|
| **水** | 低单价、高频、几乎零原料（收集器白产），利润靠“提纯档位”台阶式跳升：幽灵→基础 +50%、→优质 +125%、→纯水 +200%；纯水需要质量模组堆到 +100，形成**投资门槛**。贴标可立刻 ×2.6。 | **慢性中毒式**：错标/幽灵水进入 `dirtyWaterTracker`（单瓶即可越线，每夜只降 5），积累成 ENDANGERMENT/FRAUD 与威胁信；带试纸的黑市/治安客户当场揭穿扣声望。 | 纯度=液体 part 比例；价格=40/L×纯度修正；识破矩阵；SecData 账本（`WaterFeatureHelper.cs`, `SecData.cs:682-735`） |
| **化学** | **高杠杆**：原料几分钱、成品叠加纯度(+135%)与违禁加价(+70～150%)；工艺（温度窗口、溶剂比、蒸干、设备升级）决定纯度 → 学习曲线即利润曲线；设备升级把损耗从 35%/12% 降到 0。 | **一次爆炸式**：C2/C3 被安检查到 → 没收/罚款/逮捕；卖出劣质或有毒成品计入 badChem 账本（有毒 ×2 计危害罪）；加热过头产物分解（梦帽 >60℃、芬太 ≥130℃）。 | 化学反应 tick + 温度窗；纯度分级；违禁等级；化学反馈等级（`ChemicalHelper.cs`, `ChemicalFeedbackHelper.cs`） |

### 7.1 值得借鉴的设计手法
1. **“标签 ≠ 实物”作为通用语法**：一套 `fake/real/expose/discover` 同时支撑了收货鉴定、出货贴标、客户识破、自我合法化（Match）四种玩法，内容扩展只需新增一个 ItemCondition 列表。
2. **识破能力按客群硬编码**：让玩家形成“这个人能骗、那个人不能骗”的社会推理，而不是纯概率。
3. **延迟惩罚 + 低衰减账本**：把“道德代价”变成可预测但难以消化的债务，诱导玩家先爽后还，符合“Probably Stolen”的黑色幽默基调。
4. **生产线互为上下游**：水→水培/酿酒/化学溶剂；冶炼→枪零件/枪框；水培→化学原料/酿酒；鱼→医疗植皮。一个产业的品质（如水纯度）会传导到另一产业的品质（酒质、植物健康）。
5. **空间即机制**：网格形状来自美术、邻接决定供电与模组加成、暗格/海报决定能否被搜查——背包不仅是存储，也是“藏匿与布线”小游戏。
