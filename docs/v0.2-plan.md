## 二、补充案（来自拆解，标【补充案】，可关闭）

### 1. 货物鉴定与掺假（《可能是偷的》·标签值 vs 实际值）

- 净水、零件、绷带三类货物带「品质」：**标称品质**（货单上写的）和**真实品质**（实际的）。品质 3 档：优 / 良 / 差，价值系数 1.15 / 1.0 / 0.5。
- 供货客的货有 25% 概率**虚标**（真实比标称低 1–2 档）；贫民区 35%、富人区 15%。
- **验货**：放大镜每站 2 次（火车头自带），点「验货」揭示该供货客全部货物真实品质；虚标被揭穿时可**压价**——单拿价自动按真实品质重算。
- **掺假**：货舱里可以把 1 净水 + 1 污水兑成 2 份「标称良、真实差」的净水；零件可「翻新」（标称良、真实差）。
- **被识破**：卖给采购客时，若标称高于真实，识破率贫民区 50%、富人区 20%；识破则拒绝成交、该地区声望 −8；没识破按标称价成交，但累积「坑客记录」，每 3 次在该地区引来一名**稽查员**（下一个商业站必来），被查到货舱里有虚标货就没收并罚款 50。

### 2. 议价与地区声望（《可能是偷的》·公开概率 + 贪心税）

- 两个地区各一条声望（−100…100，初始 0）。
- 对供货客可以**压价** 10% / 25%，对采购客可以**抬价** 10% / 25%，每位客商只能议价一次，成功率在按钮上直接显示：
  - 接受率 = 100 − 2×p + 声望/6（声望为负时 ×2）；留下率 = 100 − 1.2×p + 声望/6；其余为走人（名额作废，声望 −3）。
  - 声望 0 时：10% → 80% 成 / 8% 拒绝留下 / 12% 走人；25% → 50% / 20% / 30%。
- 每笔成交按 价值÷100 加声望；议价成功时这一笔改为扣 0.5（10%）/ 1.5（25%）——**贪心会在另一本账上扣分**。
- 声望效果：≥20 采购客预算 +10%；≥50 每站来客 +1；≤−30 每站来客 −1（不低于 2）；≤−60 该地区站点拒绝上客。

### 3. 搜刮读条与品质容器（《逃离鸭科夫》）

- 探索地图里的容器分 3 个品质：普通（白）/ 精良（蓝）/ 稀有（金），权重 70 / 25 / 5（猎场 55 / 33 / 12）。
- **读条时长随品质增加**：每组揭示时间 1 秒 × 1 / 1.5 / 2；开箱时间按团队文档的容器类型。
- 精良箱额外 +1 组且空箱率减半；稀有箱必有 2 组，并从「高价池」（研究资料 25、零件 35、金属锭 25、冲锋枪 5、绷带 10）抽一组。
- 品质颜色在小地图上可见，形成「绕远路去开金箱」的风险选择。
